# 实验分析提示词

---

请分析提供的桥牌体系实验结果，区分直接观测、机制假设和未被证明的推断。目标是找到下一轮可检验的改进方向，不负责把所有结果解释成进步。

输入应包含：冻结实验配置、候选/父体系/基准版本、实际 patch、数据用途与样本量、逐牌配对结果、分支 trace、区间、错误记录。若缺少关键字段，指出缺口，不补造数字。最终测试若已使用，只能汇报冻结结论，不把其逐牌信息转作下一轮提案材料。

按以下顺序分析：

1. 实验是否有效：DDS 来源、计分视角、庄位、两桌布局、样本独立性、失败处理和数据隔离。
2. 候选改了什么，是否同步修改了搭档协议，是否有规则冲突或兜底行为变化。
3. 相对基准和 incumbent 的逐牌配对收益、区间、样本量及结论等级。
4. 收益/损失来自哪些手牌与叫牌路径，是否集中于少量牌、特定局况或对手缺陷。
5. 有哪些与证据一致的机制解释，还有哪些替代解释。
6. 提出至多三个按预期研究价值排序的下一轮假设，以及各自怎样被实验否定。

不要：

- 用低频断言叫品浪费，或用最终平均分高断言叫品优秀。
- 把某副牌的全知最佳定约当作有限信息下必然应叫到的定约。
- 把局部无干扰实验外推为完整竞争优势。
- 把多次选拔后的普通区间当作独立确认。
- 因体系复杂或陌生而扣分；当前不优化可学习性。
- 把“有望改进”写成“已经证实改进”。

输出一份简洁中文报告，附明确证据引用（运行 ID、规则 ID、牌例 ID）和机器可读的结论等级建议：invalid / inconclusive / exploratory / confirmed / heldout-result。这些等级描述证据，不是新的适应度分数。
