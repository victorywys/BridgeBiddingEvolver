# E011：全Pass起步的逼叫性Pass探索

## 起点与自由度

[配置](../experiments/e011-blank-forcing-pass.json)只选择`origins=["blank"]`：零规则、一个空公开状态、fallback为Pass，不继承E008/E010或成熟体系规则。固定CCBA/精确只用于相同对手分布下的比赛参照，不要求新体系先胜过它们。

整个general-v2体系可重写，包括开叫、应叫、人工编码、后续、竞争、加倍、成局、满贯及fallback。强牌Pass不是预设答案，点力和牌型分区由研究者决定。复杂度、新颖性及人类相似性不加减分。

## “逼叫性Pass”的本批明确定义

尚无人叫出定约叫品时，本方第一次行动在第一或第二位置选择Pass，同伴下一次行动必须作合法非Pass回应，包括有对手争叫时。非Pass可以是合法定约叫品或合法加倍/再加倍；不是强制某一具体应叫。其余中途Pass的意义由体系自行设计。

可信引擎现有公开转移的`forcing="one_round"`即可表达开叫Pass；它将义务指向行动者的同伴，不要求先有自然开叫人，也不允许读取私牌来重建公开含义。本批不新增强牌Pass点力算子或预制应叫树。

发布验收包括：

- 四个发牌位置、第一/第二位置开叫Pass、对手Pass或任意合法定约叫品，共288个公开前缀；
- 同伴公开`must_bid`必须为真，实际试走同伴Pass必须被协议拒绝，不能借`allow_pass`暗中绕过；
- 作者回归必须实际通过，至少一个空前缀自然整副变化见证真正开叫Pass、同伴非Pass回应，拍卖合法完成；
- 发布端与独立评价端分别重跑验收；正式比赛记录开叫Pass及同伴回应的实际牌族覆盖。

全Pass仅作为合法比赛基线，明确豁免目标完成要求；它本身不能作为“已经实现逼叫性Pass”的新发布物。上述有限检查不是全部私牌空间完备证明，错误与低覆盖如实保留。

## 选择与成长验证

`selection_policy="parent-improvement"`只在新共同牌上比较候选和上一开发亲本；平均配对IMP严格增加即开发升级。这里不要求击败成熟参考，不以显著性或单对手保护门槛阻止早期探索。

这是开发搜索，不是统计确认。仍保留区间、错误和所有失败提案，不把开发亲本称为全局强者；万副达标须另立冻结的正式实验。

每单元预留成长检查资源：将全Pass和历次已接受版本放到同一批现场生成的新128副上比较。相邻版本差、对初始种子的差及不确定性均保留，即使出现下降；不能用“每次挑正收益”的选择曲线冒充真实单调进步。

## 预算与运行

- 6单元，每单元160个主模型回合、最多3个不同完整发布物；
- GPT-6 Astra/high，共1100次共享请求、4000万统计token、12小时；
- 每单元512副诊断牌、2小时；每候选评价预留15分钟；
- 120000个配对预算单位，2个评价worker；不是2个并行研究写入者；
- 上下文250KB、输出16384token、结果有界限制保持，不扩大工具输出或执行任意宿主代码。

每候选16/64/256副作开发校验/筛选/完整开发评价；开发升级另用512副共同新牌。每阶段候选确定后才发牌，同轮共用，恢复重放原manifest，不预留测试池、不重抽有利牌、不补Pass或零分。

从正式CLI启动，避免stdin入口不支持spawn：

```bash
.venv/bin/bridge-evolve evolve run --config experiments/e011-blank-forcing-pass.json
```

配置、引擎、体系、作者回归、原始失败、实际上游费用收据、开发升级和成长验证均持久化。运行开始不代表已创造完整体系，也不保证单调改善；本批正是检验这些能力与框架不足。

## E013：从已接受V2继续

[E013配置](../experiments/e013-forcing-pass-continuation.json)以E011已接受的V2为亲本，不把E012中本轮收益为负的V3/V4当作已确认改进。来源回归与案例保留，旧变化见证转为亲本回归；新的发布仍需相对当前亲本的自然协议见证。

协议目标允许从已发布亲本继续，但初始化必须重跑目标验收；不接受未通过目标的全Pass骨架冒充已完成亲本，也不把未发布草稿作为目标完成的来源。成长复核包含原全Pass、继承的起始亲本和后续接受版本，不能跳过真正的本轮起点。

本批2单元、每单元160回合，上限360次共享请求、1200万统计token、4小时、60000配对。旧费用和成绩保留，本轮使用新共同牌，仍按相对上一亲本的严格正平均收益开发升级，并单列baseline弃权贡献。

已消除无意义的工具默认值报错：非packet证据读取允许空`pointer`；已完成轮次列表直接返回真实分数和状态；空candidate明确解析为当前亲本并回显。非DDS调试只有一张桌，默认`table=1`有效，`table=2`仍须DDS。导航`sections`只允许JSON相对路径，不允许把`source_node`等元数据标签当指针。
