# 评测与晋级协议

## 1. 主指标与适用范围

第一阶段主指标为实验协议规定的平均配对 IMP。不要用原始平均得分、成约率、胜率、距双明手 par 的差值或规则复杂度替代。

不同实验模式、不同抽样分布、不同对手混合下的数字不得直接比较。报告至少标明：模式、体系版本、牌例分布、局况/发牌人分布、对手、DDS 来源、样本量和置信区间。

## 2. 统一分数视角

底层计分可先返回庄家一方得分，再统一转换成南北得分 `S_NS`。东西得分为 `-S_NS`。passed-out 得分为 0，无庄家。

DDS 表按最终定约的实际庄位和 strain 查询。庄家是最终定约一方中，最早叫出该 strain 的人，不是最后一次叫出该 strain 的人。

目标墩数为 `6 + level`；实际双明手墩数可以高于或低于目标。不能仅根据“能否成约”评分。

## 3. 四人竞争：两桌同牌

给定相同 Board，不移动四手牌，不改变 dealer 或 vulnerability：

```text
桌 1：A 坐 NS，B 坐 EW，得到 S1_NS。
桌 2：B 坐 NS，A 坐 EW，得到 S2_NS。
A 的分差 = S1_NS - S2_NS。
A 的本副 IMP = signed_imp(S1_NS - S2_NS)。
```

每个基础 Board 的两桌合起来产生一个 IMP 样本，不能把两桌当作两个独立样本。B 的本副 IMP 与 A 相反。

先逐副转换 IMP 再求平均；不能先平均分差再转 IMP。对手混合下，按固定权重汇总各对手的平均 IMP。

## 4. 无干扰局部实验

首个实验固定 N 开叫 1NT、E Pass，N 满足公开的 15–17 HCP、4333/4432/5332 均型条件，S 轮到行动；W/E 后续始终 Pass。候选和基准使用相同前缀、相同四手牌、相同局况。

分别让候选搭档和基准搭档在 NS 完成叫牌，得到 `S_candidate_NS` 与 `S_reference_NS`：

```text
local_imp = signed_imp(S_candidate_NS - S_reference_NS)
```

这不是 A 对 B 的两桌竞争比赛；不要套用竞争模式并声称获得竞争胜率。报告标签必须为 `uncontested-1nt`，其结论只适用于固定开叫条件与对手 Pass 的局部协议。

若以后演化 1NT 的开叫范围，必须在共同的未筛选牌例分布上重测；不能让各候选按自己的开叫条件挑不同牌例。

## 5. 双明手奖励的含义

DDS 以四手牌公开、双方最优打牌为假设，是终局打牌的近似。它不表示叫牌时知道四手牌，也不是唯一正确定约标签。

禁止把逐副最好的全知定约直接当作每一步必须选择的动作。需要比较当时信息下固定策略在大量牌例上的成绩，而不是在每副牌上事后挑动作。

par 可以作诊断参考，不能作为主要适应度或不完全信息下可达的保证。双明手与真实不完全信息打牌的成绩可能有系统性差异，正式报告必须标注。

## 6. 现场随机抽样与不可见性

- 不预留`train/validation/test`牌池；E002每个诊断、有效性、筛选、确认及10000副检测轮次都现场随机生成。现有manifest的split是兼容用途标签，不表示预留数据。
- 新候选先确定，后生成用于比较的新牌；同轮所有候选、父版本和对手共享完整输入。
- 保存生成算法、种子及manifest用于复现；种子非必填，不进入运行期策略观察。重试/恢复重放该轮清单，不重抽更有利的牌。

按基础牌族核对唯一性：同一四手牌的局况、发牌人和座位旋转不是独立样本。DD缓存可复用，但研究Agent不能查询尚未完成轮次的牌和结果；旧版`agent`只收分析包，E003的`research`可通过工具阅读批准的完整历史记录、生成诊断牌、运行实际调试及探索比赛。

全部完成轮次都可供之后分析。之后的提升结论须来自新的随机轮次，不能把旧数据重标成未见过的新证据；多次看结果仍须事先分配总错误预算。

## 7. 公平比较与方差

同一轮候选使用相同牌例、对手版本、对手权重和调度配置。候选与 incumbent 在同一对手上的逐牌 IMP 作配对比较。

对每个基础牌族先汇总相关变体，再计算均值和不确定性；不能把同牌多局况、多对手、两桌或随机重放当作独立牌扩大样本量。

默认用按基础牌族重采样的配对 bootstrap 给出 95% 区间。初版使用预先固定的样本量，不根据中途普通置信区间随意提前停止。以后若加入逐步淘汰，另行实现适用于连续观察的统计规则。

数千或上万副只是工程起点，不保证能检测很小的收益。小样本冠军通常存在筛选偏差，必须独立确认。报告不得把区间跨 0 的结果写成已证明提升。

## 8. 种群、对手与排名

有效候选按同一冻结评测配置下的平均 IMP 排名，保留 top-k 和 incumbent 的完整版本记录。并列时保留原 incumbent 或按稳定内容哈希排序，不以复杂度破同分。

保存全部历史体系。竞争模式的对手池可以包含固定基准、历史版本和当前版本；采样规则和权重必须在评测前冻结，不能针对候选临时调节。

E003研究中的条件牌、反复试验及独立讨论均为开发证据，不是独立晋级证据。通过有效性门禁的候选都可进入完整复筛，不因小样本平分用哈希淘汰；相同候选仍可补足未完成评测。随机复筛未改变任何叫牌时记为`insufficient_coverage`，而不是判定设计无效。实际改变行为且复筛均值非负的候选可申请新牌确认，确认仍须满足冻结的`0.05 IMP/副`点估计、校正单侧下界及单对手保护条件；同谱系可在共享尝试预算内依次确认多个替代方案，晋级至多一个，旧版`agent`保留原筛选方式。

不设置“简洁体系名额”或因可读性加分。历史归档和对手池覆盖用于实验有效性，不构成复杂度适应度。不能把本轮新对手池的分数与上轮旧池的分数直接当作连续提升曲线；跨代曲线另用固定锚定评测配置。

冠军晋级时，将候选与 incumbent 在同一新确认块和冻结对手混合上配对重测。均值更高但证据不足时可标记 promising，不宣称 confirmed。确认门槛在实验前设定；固定多个候选同时确认时处理多重比较，避免反复挑显著结果。

## 9. 公开体系信息

两方都能获取对方事先公开的完整协议说明。引擎提供公开说明，不等于固定规则对手会主动适应。

报告区分固定对手表现和适应后的对手表现。新叫品若主要依靠固定对手误解获利，应如实说明；后期可训练或设计有适应能力的对手复测，但不要把适应前后的数字混合。

## 10. 失败不能静默消失

非法动作、规则冲突、崩溃或协议执行错误会使候选本次评测无效，并保留原始错误。基础设施错误标记 run failed，修复后按相同配置重试。

不能删掉失败牌例后计算均值，也不能将失败默认记为 Pass、0 分或随机定约。与项目指定的可执行约定不一致，需要明确是候选缺陷还是实现缺陷。

## 11. 规则来源

通用叫牌状态与计分参照 [WBF 规则入口](https://www.worldbridge.org/regulations/2017-laws-of-duplicate-bridge/) 中的规则，重点核对结束叫牌、定约/庄家、加倍/再加倍、Law 77 计分和 Law 78 IMP 表。数值边界应从权威版本核实后写成固定测试，不依赖大模型回忆。

该引擎先处理合法叫牌，不需要实现裁判纠正程序；也不把具体赛事的约定准入政策当作当前搜索空间限制。

## 12. E002进化实验的具体协议

完整配置及推导见[E002设计](12-self-evolution.md)，首次运行前冻结：

- 起点兼固定锚点为当前CCBA/精确工程v5.5.3；候选晋级只更新其谱系冠军，不替换原对手。
- 开发筛选对两个锚点等权计算平均配对IMP；晋级必须在新的共同牌块上比较候选与当前冠军的**逐牌收益差**，不能用独立均值或区间是否重叠代替。
- 晋级确认次数有限，错误预算分配到各次确认，断点恢复不重置预算。各固定对手的单独变化也必须报告。
- 最终选择一个冻结候选，在同一份全新10000副上分别对战两个原对手：40000桌、20000个两桌配对，但仅10000个独立基础牌族。
- 对两列逐牌成绩使用同一批牌族重采样索引，处理两个比较。建议最终名义总`α=0.05`、20000次bootstrap，各取97.5%单侧下界；两个下界均大于0才称分别统计显著，均大于建议的`0.20 IMP/副`才称达到“非常明显提升”强目标。
- 默认最终只看一次。多候选/多次最终尝试必须事先扩大比较族并分配总错误预算；不能反复换测试牌重置显著性水平直到通过。

界面允许保存失败牌和有效子集作诊断，不代表这些子集可以参与进化排名。候选缺陷使候选无效；固定对手、引擎或基础设施故障使比较阻塞/失败，不自动判候选获胜。原对手需要修复时，另立实验版本并明确目标改变。

上述规则已接入[进化执行器与控制器](../src/bridge_evolve/evolution/)；原有单次`evaluate`仍是独立入口，不会自动变成多代进化实验。E003另外要求发布前实际运行Agent编写的断言和行为变化见证，但这些测试及随机语义门禁都不等于穷尽所有边界的协议证明，运行完成也不等于强目标通过。
